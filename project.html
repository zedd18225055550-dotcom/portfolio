IP Setting

Map Logic from route to world.

把旧式棋盘路径升级成全景会场：用户仍然能快速理解路线，但页面可以容纳品牌露出、奖励节点、NPC 和更复杂的互动层级。

  1. 01 旧方案只解决“走格子”，沉浸感和节日价值感不足。 旧问题：棋盘路径只能说明任务怎么走，却承载不了品牌会场、奖励关系和节日氛围，用户缺少继续探索的理由。
  2. 02 新方案把路径、奖励、品牌商铺和角色引导放进同一张地图。 新方案：把路径节点、商铺露出、角色引导和奖励反馈合进全景地图，让用户仍按路线推进，但感知从“走格子”变成“逛会场”。
  3. 03 线稿阶段先做信息分层，保证复杂场景压到手机后仍然能读。 结果：地图成为活动信息总控，既能引导任务和转化，也能放大品牌露出；复杂场景压到手机视窗后仍然保持可读。

Map Setting scene proof.

第二章补地图设定本身：先看完整预览，再把道路、龙门和场景细节拆到线稿层，说明这张地图不是单张氛围图，而是可被手机视窗、任务节点和奖励路径反复验证的系统。

Dragon Gate Gradient.

五张地图需要一眼属于同一个玩法，又不能只是换背景。龙门被拆成可复用的入口母题，再通过结构复杂度、色彩强度和奖励感逐级升级。

  1. WHY避免五张散图同一套龙门结构保证用户每进一关都知道“这里是任务入口”。
  2. GOAL制造进度感从轻量门型到完整建筑，让用户感觉难度、奖励和主会场价值在升级。
  3. METHOD结构不变，表现递进门型、台阶和圆形动线保持一致，材质、装饰和光效逐层加码。
  4. RESULT可复用的关卡资产龙门同时承担地图识别、奖励引导和最终分享画面的视觉锚点。

Five Map Venues one festival route.

五张地图单独释放出来横向浏览：地域建筑、路径长度、奖励节点和节日情绪都各自成立，同时保持同一套龙年会场规则。

2024 / 龙年 CNY

PROJECTS/
CNY IP & MAP
SYSTEM

把龙年预热活动从分散物料整理成一套可延展的 IP、地图会场和移动端视觉系统。

Role创意主 R / 视觉定调 ScopeIP / Map / Posters / Mobile Year2024 龙年

Project Overview

From campaign assets to a reusable festival system.

项目目标不是只完成一组春节视觉，而是在有限时间里统一“龙年 IP、五个主题会场、分享海报、挂件与移动端落地”。我负责从创意方向、视觉风格到最终输出质量的整体把控。

When I joined

CNY 预热期，视觉方向需要快速从概念发散进入可落地系统。

Business goal

让预热会场不只是入口集合，而是有探索感、记忆点和分享动机。

Core tension

五个地域主题要明显不同，但整套活动又必须一眼属于同一个龙年世界。

My role

对接创意需求、定调 IP 与地图风格、整合输出、视觉后期兜底。

Strategy Pivot

The hard choice was not style. It was structure.

普通活动页会把信息平铺给用户看；这次我把会场做成“可以走进去的地图”：五个地域关卡对应五种建筑、色彩和路径节奏，用户不是扫入口，而是在春节世界里移动。

V1 / Asset thinking

每张海报、每个会场各自成立，但上线后容易变成散装物料，后续加内容也需要重复重做。

V2 / System thinking

先定义 IP 规则、地图规则、颜色和地域关卡，再把物料作为系统的不同出口。

IP System

Series consistency first, then character variation.

Color

用春节红、金色、粉色和地域色建立统一但不单调的节日情绪。

Pattern

纹样、符号和配饰负责把角色、地图、海报拉回同一个世界观。

Expression

通过五官、动作和表情差异，让 IP 在不同场景里有可爱的叙事弹性。

Output

从主 IP 到挂件、分享海报、移动端页面，规则先行，输出才不会散。

Map System

Five regions, five moods, one panoramic route.

Design Process

Path, scale, color, then final scene.

全景式地图的难点是步数由低到高，路径变长，画幅变大，人力和时间成本同步放大。所以我把设计拆成路径标准、建筑结构、场景元素、配色体系四个层级，再进入线稿和成稿。

01路径与步数规划 02地域建筑风格研究 03线稿、上色、最终合成

Result

The system shipped as campaign memory.

User feedback

Internal recognition

作为优秀项目沉淀，证明这套系统不只是好看，而是能被复用和传播。

Final Output Wall

Many exits, one campaign.

把活动主页、地图节点、领奖海报和结束页放到最后收尾：前面讲规则和制作过程，这里集中证明整套系统能落到真实活动链路里。
